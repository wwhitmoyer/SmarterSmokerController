# Repository working instructions

## Turn user feedback into GitHub issues

When the user provides actionable feedback about this repository—such as a bug,
requested enhancement, usability problem, missing behavior, or concrete
follow-up—create a GitHub issue in this repository.

- Write a concise, specific issue title.
- Preserve the user's intent and relevant wording in the description.
- Add useful context, expected behavior, acceptance criteria, and reproduction
  steps when they can be inferred without inventing facts.
- Check existing open issues first and update or reference a matching issue
  instead of creating a duplicate.
- Do not create issues for casual opinions, questions, acknowledgements, or
  feedback unrelated to this repository.
- After creating or updating an issue, tell the user which issue was affected
  and provide its link.
